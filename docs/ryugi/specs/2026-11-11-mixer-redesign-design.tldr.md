# Mixer 页面重做 · 摘要

完整文档：[2026-11-11-mixer-redesign-design.md](./2026-11-11-mixer-redesign-design.md)。效果图：[2026-11-11-mixer-redesign.png](./2026-11-11-mixer-redesign.png)。

## 做什么

只改 `packages/render/web`。服务端、DSP、谱面语法都不动。

## 做完后你会看到

1. 顶栏三等分：左边标题和文件路径，正中间是播放、时间、循环，右边是测量状态和 Export。
2. 地图上直接拖每一段的目标响度，0.5 LUFS 一格。
3. 地图左侧是五个读数：整曲、范围、真峰值、限幅量、母带增益。
4. 每条轨道左边自带推子、M、S，点名字展开 Pan 和 Send。
5. 右栏是谱面里真实的 `form`、`mix`、`space`、`master` 行，数值是可点的小块，点开在行下出滑杆。改过的行左侧有黄条，右侧写"was 旧值"和撤销。
6. 底栏常驻：`N lines changed · 行号`、Revert all、`Write N lines to 文件名`。
7. 字体换成 IBM Plex Sans 和 IBM Plex Mono，打包进页面。

## 请检查这些（我自己定的）

- **自动测量：** 停止编辑 800 ms 后自动测，去掉 Measure 按钮；点状态可以手动再测。
- **mix 行的数值块：** 点它是展开左边那条轨道，不在右栏再出一个滑杆，避免同一个推子出现两次。
- **幽灵行：** 谱面里没写的默认值（没有目标的段、没有 `space` 或 `master` 行、`lowcut`、`presence`、`air`、`fade`）用淡色占位显示，点了就能改，改了才真的写进谱面。
- **读数多一行：** 效果图是四个，我保留了原来的母带增益，共五个。
- **底栏常驻：** 没改动时显示 "No changes"，Write 置灰。
- **删掉的东西：** 顶栏的 `score 0.3` 标签、"Sounding in B1" 的声部标签列表、五个标签页、单条改动的 diff 卡片。
- **中文和日文：** 用系统字体兜底，不打包 IBM Plex Sans JP（太大）。
- **循环按钮：** 文案是 `Loop {段落}`，跟着播放头所在的段落走，不是跟着选中的段落；播放器行为不变。
- **撤销的粒度：** 每行单独撤销。`master` 拆成首行、`lowcut`、`presence`、`air` 四块；`space` 只有一行，所以整行一起撤销。
- **没有轨道的 mix 行：** 某个乐器的声部都各自有 mix 行时，它自己那行只显示、不可改，和现在一样。
- **旧版谱面：** 0.1 或 0.2 的文件写入时会顺带改 `score` 版本行，这些行在右栏顶部列为 "Also changes"，计入行数。
- **效果图里的 `80%`：** 实际页面显示 `rewriteScore` 真正写出的文本，改过的 mix 行会是 `-1.9 dB`。

## 时间

我来实现，大约 40 到 60 分钟，含测试和在浏览器里核对。
